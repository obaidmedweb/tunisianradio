# Tunisian Radio Player

A modern radio streaming application for listening to Tunisian radio stations. This application works on both Windows and Mac.

## Features
- Clean and professional user interface
- Support for multiple Tunisian radio stations
- Simple play/stop controls
- Bilingual interface (Arabic/English)

## Requirements
- Python 3.8 or higher
- PyQt6
- python-vlc
- VLC Media Player must be installed on your system

## Installation

1. First, make sure you have VLC Media Player installed on your system
2. Install the required Python packages:
```bash
pip install -r requirements.txt
```

## Running the Application
```bash
python tunisian_radio.py
```

## Available Radio Stations
- Radio Tunis
- Radio Jeunes
- RTCI
- Radio Culture
- Radio Sfax
- Radio Monastir
- Radio Gafsa
- Mosaique FM
- Express FM
- Shems FM

## Usage
1. Select a radio station from the dropdown menu
2. Click "Play" to start streaming
3. Click "Stop" to stop the playback
